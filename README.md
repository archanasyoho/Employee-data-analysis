Employee Data Analysis Project

Project Overview

This project focuses on Employee Data Analysis using Python and Pandas.

The main objective is to understand employee attrition and identify factors that influence employees leaving an organization.

Dataset

IBM HR Analytics Employee Attrition Dataset.

Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook
- Git and GitHub

Data Analysis Performed

1. Loaded the employee dataset.
2. Checked dataset shape.
3. Checked dataset information using info().
4. Generated statistical summary using describe().
5. Checked missing values.
6. Checked duplicate records.
7. Analyzed employee attrition.
8. Created a data dictionary.

Business Questions

1. Which department has the highest employee attrition?
2. Does overtime affect employee attrition?
3. Which age group has the highest employee attrition?
4. Does job satisfaction affect employee attrition?
5. Does monthly income have any relationship with employee attrition?

Conclusion

This project provides an initial understanding of employee data and attrition patterns using Python.
